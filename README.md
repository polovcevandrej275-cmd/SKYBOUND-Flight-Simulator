# SKYBOUND — браузерный симулятор полётов

Интерактивный демонстрационный сайт с картой мира, выбором аэропортов, построением маршрута и анимированным самолётом.

## Что работает
- Интерактивная карта на Leaflet + OpenStreetMap.
- 16 аэропортов в разных регионах мира.
- Выбор аэропортов вылета и назначения, обмен местами.
- Расчёт расстояния по дуге большого круга и примерного времени.
- Анимированное движение самолёта, пауза, продолжение и сброс полёта.
- Регулировка скорости и отображение прогресса.
- Адаптивный интерфейс для телефона и компьютера.

## Запуск на компьютере
1. Распакуйте `skybound_flight_simulator.zip`.
2. Откройте `index.html` в современном браузере.
3. Для карты и шрифта нужно подключение к интернету: библиотеки, карты и шрифт загружаются с внешних CDN.

Если браузер ограничивает некоторые функции при открытии файла, запустите локальный сервер из папки проекта:
- Python установлен: `python -m http.server 8000`
- Затем откройте `http://localhost:8000`

## Публикация в интернете (GitHub Pages — бесплатно)
1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый публичный репозиторий, например `skybound-flight-sim`.
3. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `script.js`.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
7. Подождите публикации. GitHub покажет публичный адрес в настройках Pages; он обычно выглядит как `https://ВАШ-ЛОГИН.github.io/skybound-flight-sim/`.

Альтернатива — Netlify: https://app.netlify.com/drop. Войдите в аккаунт и перетащите распакованную папку сайта в область загрузки, если этот вариант доступен в вашем аккаунте.

## Важно
Это браузерная симуляция, не реальный авиационный тренажёр: нет реальных погодных данных, ADS-B, управления аэродинамикой или подключения к самолётам. Маршрут и длительность полёта рассчитаны для демонстрации. Карта использует OpenStreetMap; соблюдайте условия использования тайлов и атрибуцию. Не удаляйте подпись OpenStreetMap с карты.
